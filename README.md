# MeriShop — Shop Management App for Small Retailers

**MeriShop** is a free Android shop management app built with **Flutter & Dart** for small retailers, kiryana stores and shopkeepers. It replaces paper ledgers with simple digital inventory, billing and sales records — no internet or account needed.

## Features

- **Inventory management** — add products with cost price, sale price and stock levels
- **Fast billing** — create a sale in seconds, stock updates automatically
- **Sales history & daily reports** — see today's sales, profit and best-selling items
- **Low-stock alerts** — know what to reorder before it runs out
- **Offline-first** — all data stays on the phone, works without internet
- **Lightweight** — runs smoothly on budget Android phones

## Tech Stack

- Flutter / Dart
- Android (also structured for iOS & Web)
- Local on-device storage

## Getting Started

```bash
flutter pub get
flutter run
```
